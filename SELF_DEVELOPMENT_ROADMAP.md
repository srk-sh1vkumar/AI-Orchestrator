## 🔄 Weekly Tracking Workflow

### Step-by-Step Process (45 minutes/week)

**Step 1: Log Learning Hours** (10 min)
```bash
# Example: Log 8 hours of AI architecture work
curl -X POST http://localhost:8000/api/tracker/learning-sessions \
  -H "Content-Type: application/json" \
  -d '{
    "id": "week-42-ai-arch",
    "goal_id": "ai-systems-design-mastery",
    "duration_minutes": 480,
    "description": "Worked on context-aware routing pattern",
    "notes": "Implemented pattern, wrote tests, documented usage"
  }'
```

**Step 2: Update Progress** (15 min)
```bash
# Update goal progress after completing milestones
curl -X PUT http://localhost:8000/api/tracker/goals/ai-systems-design-mastery \
  -H "Content-Type: application/json" \
  -d '{"progress": 25}'

# Update skill proficiency
curl -X PUT http://localhost:8000/api/tracker/skills/context-aware-routing \
  -H "Content-Type: application/json" \
  -d '{"proficiency_level": 3}'
```

**Step 3: Write Reflection** (15 min)
```bash
# Create reflection entry
curl -X POST http://localhost:8000/api/tracker/reflections \
  -H "Content-Type: application/json" \
  -d '{
    "id": "reflection-week-42",
    "date": "2025-10-19",
    "content": "This week I made significant progress on context-aware routing. The pattern is working well in tests. Challenge: handling edge cases with context overflow. Solution: implemented context pruning strategy. Next: integrate into v2 architecture.",
    "mood": "productive",
    "tags": ["ai_systems_design", "context-routing", "architecture"]
  }'
```

**Step 4: Tag Entries** (5 min)
- Ensure all entries tagged with appropriate `goal_id` or integration tags
- Review tags for consistency
- Add additional tags for themes or topics

**Step 5: Review Dashboard** (Auto/Manual)
```bash
# View your metrics
curl http://localhost:8000/api/tracker/metrics | jq

# Generate weekly summary
curl http://localhost:8000/api/tracker/summary?period=week | jq
```
